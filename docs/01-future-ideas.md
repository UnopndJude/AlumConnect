# AlumConnect 미래 아이디어

> 이 문서는 향후 검토할 아이디어들을 정리한 것입니다.
> 우선순위: 기본 기능 완성 후 단계적 도입 검토

## 현재 모델의 한계

| 문제            | 원인                            |
| --------------- | ------------------------------- |
| 정보 노후화     | 정적 프로필, 업데이트 동기 부재 |
| 프라이버시 부담 | 일방적 정보 공개 구조           |
| 낮은 참여율     | "채워야 할 양식"이 진입장벽     |

## 아이디어 목록

### 1. 시간 기반 의도(Intent) 모델

프로필 대신 "지금 원하는 것"만 공유하는 방식

- 예: "이번 달 커피챗 가능" (30일 후 자동 만료)
- 정보가 자연스럽게 휘발됨
- 업데이트 부담 없음
- 활성 사용자만 노출

### 2. 익명 Q&A 중심 모델

정보 공개 없이 도움 주고받는 구조

- 질문자/답변자 모두 선택적 신원 노출
- 쌍방 동의 시에만 연결
- 실질적 가치 중심

### 3. 역할 토글 모델

구체적 정보 없이 현재 상태만 표시

- 멘토링 가능 / 커피챗 환영 / 채용 중 등
- 켜고 끄기만 하면 됨
- 세부 정보는 연결 후 공유

### 4. 이벤트/모임 중심 모델

프로필 대신 참여로 존재 증명

- 관심사로 자연스럽게 그룹핑
- 오프라인 연결이 온라인 프로필보다 효과적

### 5. 요청-응답 매칭 모델

블라인드 매칭 후 쌍방 동의

- 정보 노출 최소화
- 도움 줄 의사 있는 사람만 참여

## 핵심 방향성

**"나는 누구다" → "지금 무엇을 원한다/줄 수 있다"**
