# Ralph Progress Log
Started: 2026-02-12T00:00:00Z

## Project
Alumni Push - Newsletter-First Alumni Platform

## Branch
ralph/alumni-push-newsletter

## Architecture Decision
- **Authentication**: Supabase Magic Link (passwordless)
- **User Flow**:
  ```
  Email → Magic Link → Onboarding (Alumni DB 매칭 필수) → [선택] Quiz → Verified Badge
  ```
- **Alumni DB**: 온보딩 시 매칭 필수 (기존 기능 유지)
- **Quiz**: 선택적 - 통과 시 'Verified Alumni' 배지
- **확장성**: 향후 멀티 커뮤니티 지원 가능한 구조 (community_id 예약)

## Access Tiers
- **Public**: 뉴스레터 아카이브, 이메일 구독
- **Authenticated** (Alumni DB 매칭 완료): 프로필, 구독 설정, 디렉토리 (제한적)
- **Verified** (Quiz 통과): 전체 디렉토리, 네트워킹, 소식 제보, opt-out

## Code Changes
- **Remove**: Password field, password-based auth, admin approval workflow
- **Modify**: User → Profile (linked to auth.users), Quiz becomes optional
- **Retain**: Alumni DB + AlumniMatchingService, Quiz system, Introduction, Supabase infra

## Codebase Patterns
- Clean Architecture with DDD
- Repository pattern (Supabase + InMemory)
- Result<T, E> error handling
- No semicolons, 2-space indentation
